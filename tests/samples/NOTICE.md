# Sample files

These Altium files are copied unmodified from the `altium` crate's test
samples (https://github.com/pluots/altium, `altium/tests/samples/`),
licensed Apache-2.0. `simple.csv` is the object list Altium exported for
`simple.PcbDoc`; the PCB tests use it as ground truth.

| File | Upstream path |
|---|---|
| `simple.SchDoc` | `schdoc/simple.SchDoc` |
| `simple.SchLib`, `graphic-mixed.SchLib`, `long-pindata.SchLib` | `schlib/` |
| `simple.PcbDoc`, `simple.csv` | `pcbdoc/` |
| `Simple.PcbLib` | `pcblib/` |
| `simple-proj.prjpcb` | `prjpcb/` |
